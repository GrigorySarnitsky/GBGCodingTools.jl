A package's own settings, read as data.

GBGCodingTools.ConfigIO — Module
ConfigIO

Reading a package's own two Julia files — .gbg/config.jl, its settings, and .gbg/settled.jl, the rulings its owner has already given — without evaluating them. Both are parsed, and only literals and keyword calls to the constructors of Model are accepted: a function call, an interpolation, an unknown keyword or an unknown constructor is refused.

The reason is not tidiness. A config that is included is a program, and a module holding nothing but a configuration type still ran getpid() through it when that was tried. A package's settings are read by every build and every test of that package; they must be data.

Refusals are ConfigError, which every verb turns into exit 2 — the consumer's mistake, not a crash of this package.

GBGCodingTools.ConfigIO.ConfigError — Type
ConfigError

A .gbg/config.jl or .gbg/settled.jl that cannot be read as data.

Fields

  • file — the file it was raised for.
  • problems — one line per refusal, each naming what was found and where.

GBGCodingTools.ConfigIO.read_config — Function
read_config(root) -> Model.Config

The package at root read from its .gbg/config.jl, as data. The argument is root, the package root. Throws ConfigError when the file is absent, does not parse, or holds anything but literals and the constructors above. Returns the config.

source
GBGCodingTools.ConfigIO.read_settled — Function
read_settled(root) -> Vector{Model.Settled}

The rulings the owner has already given, read from .gbg/settled.jl as data; an absent file is no rulings, which is the ordinary state of a new package. The argument is root, the package root. Returns the rulings, in the order they were appended.

source
GBGCodingTools.ConfigIO.read_value — Function
read_value(path) -> Any

The one value the Julia file at path holds, built from its parse tree without evaluating it. The argument is path, the file to read. Throws ConfigError listing every refusal, so a reader sees all of its mistakes at once rather than one per run. Returns the value.

source
GBGCodingTools.ConfigIO.validate — Function
validate(cfg, root) -> Vector{String}

What is wrong with the config as a description of the package at root: a command that names no file, a declared copy whose source is missing, a switch with no reason, a file set whose patterns match nothing. The arguments are cfg, the config, and root, the package root. Returns one line per problem, empty when there is none.
