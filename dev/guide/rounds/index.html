Rounds

Written by AI, not regularly reviewed

This page is written by AI and is not reviewed regularly by a human.

A round is one run of one instrument over one consumer, tracked under .gbg/rounds/<date>-<instrument>-<NN>/. The CLI writes its marker ROUND.toml; the lane agents — one agent per surface or territory the instrument covers, a lane — write their lane files; the CLI banks, the session fixes, the verifiers grade, the CLI closes. Nothing is done by hand that a verb does.

The lifecycle

  1. Open — gbg preflight <instrument> (the skill's ! block): the quick doctor, the torn-file guard, gbg self verify; the roster resolved; ROUND.toml written with every stamp; the Workflow scripts copied into .gbg/scratch/<round>/workflow/ and every payload written beside them as a file.
  2. Prepare — gbg round prepare <round>: the build under GBG_ROUND, the manuscripts consolidated (and seeded), or the scan battery banked as lane 00-scans, or the audit's diff files.
  3. Lanes — the printed Workflow call; each lane writes findings/NN-<lane>.json first.
  4. Bank — gbg round bank <round>: lane files validated and classified (a DEAD lane is exit 2 and nothing is frozen), ids <round>/<lane>#<n> assigned, seeds marked, findings.json frozen.
  5. Fix — on the owner's word, from findings.md by id; builds and tests through gbg round build|test <round>.
  6. Verify — gbg round pass open <round>: a nonce, the range, the regenerated manuscripts; the act verifier (sees the diff) and the state verifier (blind) launched as printed.
  7. Grade — gbg round grade <round>: the demotion, the closure channels, the tally; exit 1 while any id is open. Loop 5–7 over the same findings.json.
  8. Close — gbg round close <round> when every condition holds; gbg round abandon is the only wholesale exit and names every open id.

Closure channels

ChannelCondition
honoredact HONORED after demotion and state ABSENT or NOT-A-DEFECT in the same pass
adjudicateda ledger entry scope = "finding" naming the id, reason ≥ 40 characters, overturn_when present, recorded after the round opened; audited at close
seededa planted finding whose state is favourable
rescana hard-scan hit of lane 00-scans that no longer fires when grade re-runs the scan

The demotion is mechanical: HONORED with an empty class_surfaces[] becomes LINE-ONLY.

The gate

gbg gate [instrument…] fails on any open round of the named instruments except the one named in GBG_ROUND, which the CLI exports only while it runs a build or a test on that round's behalf. The makedocs wrapper runs it for the doc instruments and TestHarness.gate() for the code instruments, so a fix pass cannot be committed around an open round.
