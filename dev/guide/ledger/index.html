The ledger

Written by AI, not regularly reviewed

This page is written by AI and is not reviewed regularly by a human.

.gbg/exemptions.toml is the one place a consumer — a package that pins this tool and is reviewed by it — records a waiver or an adjudication. One [[exemption]] per entry:

[[exemption]]
id       = "RULE.DOC.STEER"       # a RULE.* rule, a SCAN.* scan, a doctor check, a finding id, or a harness op
scope    = "policy"               # policy | scan | lint | check | finding | harness
target   = "*"                    # or a symbol, a file, a glob, a finding id
reason   = "at least 40 characters: what is declined and why"
recorded = 2026-08-25
expires  = 2027-08-25             # required for every scope but finding; at most recorded + 365 days
evidence = "IT CLAUDE.md:179-182"

A scope = "finding" entry is the adjudication channel: it carries overturn_when instead of expires, closes exactly one banked finding, and is audited by the dismissal auditor at close. Its optional ruling says which kind of adjudication it is: not-a-defect (the default) rules the finding no defect, and its reason reaches every later panel and verifier as settled; scoped puts a real defect outside the round's reach, closes it, and is never shown as settled. An optional [exemption.match] table (arg_name, arg_type, path, symbol, ANDed) refines a scan, lint, policy or harness entry: the engine applies the predicate per trigger and the rule stays live elsewhere; arg_type is evaluable by the reflection scans only, and a text scan refuses it.

The doctor's CFG.EXEMPTIONS validates every entry; EXEMPT.EXPIRED fails on a lapsed one, EXEMPT.EXPIRING warns within 30 days, EXEMPT.STALE on a target that no longer exists, and EXEMPT.BROAD when one match covers more than half of its rule's triggers. The families PIN.*, CFG.*, EXEMPT.*, WIRE.*, MANAGED.*, SHIM.*, POL.*, ROUND.*, SELF.* are never exemptable.

GBGCodingTools.Ledger.read — Function
Ledger.read(cfg) -> Vector{Dict{String,Any}}

Every [[exemption]] of <root>/.gbg/exemptions.toml, schema-validated. Returns an empty vector when the file is absent (an empty ledger is a legal state) and throws a LedgerError when it does not parse or does not validate — an unreadable ledger is never treated as empty.

GBGCodingTools.Ledger.entries — Function
Ledger.entries(ledger, id; scope = nothing, live = true) -> Vector

The entries naming an id. The arguments are:

  • ledger — the entries Ledger.read returned.
  • id — the id to select.
  • scope — one scope to restrict to (any when nothing).
  • live — whether to drop an entry past its expires date (it no longer exempts anything, and the doctor reports it).

Returns the selection in file order.

GBGCodingTools.Ledger.matches — Function
Ledger.matches(entry, root; file = "", symbol = "", arg_name = nothing, arg_type = nothing) -> Bool

Whether entry covers a trigger. The arguments are:

  • entry — the ledger entry.
  • root — the consumer root; globs in target and match.path resolve against the file's relative path, so root only names the tree.
  • file — the trigger's file, relative to the root.
  • symbol — the trigger's owning binding.
  • arg_name — the argument name, for a reflection scan's trigger.
  • arg_type — the argument's declared type, for a reflection scan's trigger; a text scan passes nothing and refuses an entry carrying match.arg_type before calling — this function throws on it.

The entry covers the trigger when its target is *, equals file or symbol, or is a glob matching file; and, when it carries a match table, every present sub-key holds (path a glob over file, symbol a regex over symbol, arg_name a regex, arg_type a type name tested by <:). Returns the boolean.
