The verbs

Written by AI, not regularly reviewed

This page is written by AI and is not reviewed regularly by a human.

gbg <noun> <verb> is the whole command line; the table is closed, and every verb below is rendered from its own docstring so the page cannot drift from the code. The exit contract is one for all: 0 clean, 1 a substantive finding, 2 cannot evaluate (refused, missing input, torn file), 3 crash.

Entry point

GBGCodingTools.main — Function
main(args) -> Int

The one entry point of the command line: the shim execs julia -e 'using GBGCodingTools; exit(GBGCodingTools.main(ARGS))', and every test of a verb calls it directly. Dispatches <noun> <verb> (or a lone noun) through VERBS and returns that function's exit code: 0 clean, 1 substantive finding, 2 cannot evaluate, 3 crash. A --dev first argument sets GBG_DEV=1 so the stamps read dev+<sha>, exactly as the shim's --dev route does. An exception escaping a verb is printed with its backtrace to stderr and returns 3, so a crash is never read as a finding; an unknown verb prints the table and returns 2. Output is never truncated.

source
GBGCodingTools.parse_options — Function
parse_options(args; valued = String[]) -> Options

Parses args into an Options. An option named in valued consumes the next argument as its value (or the text after =); every other --name is a flag; a lone -- ends option parsing. Returns the parsed options; an option that is in valued but has no value is an ArgumentError.

Machine and self

GBGCodingTools.cmd_install — Function
cmd_install(args) -> Int

gbg install [--dev-checkout <path>]: copies the running copy's bin/gbg to ~/.local/bin/gbg with mode 755 and, with the option, writes the one-line pointer ~/.gbg/dev. Runs from whichever copy Pkg resolved for the calling environment — no depot glob is ever expanded. Returns 0 when both files are written, 2 when the Julia in use is below the floor, when --dev-checkout names a directory that is not a GBGCodingTools checkout, or when ~/.local/bin is not on PATH (the shim would be installed but never found).

source
GBGCodingTools.self_verify — Function
self_verify(root = Config.find_root(); io = stdout) -> Int

Recomputes the git tree hash of the copy this process runs from (pkgdir(GBGCodingTools), through TreeHash.tree_hash) and compares it with what Pkg.dependencies() reports for the tool in the active environment and with the git-tree-sha1 every sub-environment manifest under root records; asserts the dependency entry is is_tracking_repo && !is_tracking_path (a Pkg.develop'd copy lives inside the depot, so only the flags tell it apart). Prints one line per comparison to io. Returns 0 when every comparison agrees, 0 with a WARN when the running copy is a working tree (pinned at dev) or no manifest exists to compare against, and 2 for a disagreement or a developed copy — an edited pinned tree is never allowed to grade a round.

source
GBGCodingTools.cmd_probe — Function
cmd_probe(args) -> Int

gbg probe [--fail]: exists for the platform verification V2 and nothing else. Prints PROBE OK and returns 0; with --fail prints PROBE FAIL to stderr and returns 2. Reads and writes no file.

Consumer setup

GBGCodingTools.Init.init — Function
init(root = pwd(); migrate = false, dry_run = false, io = stdout) -> Int

gbg init [--migrate] [--dry-run]: seeds a consumer. The arguments are:

  • root — the package root (the directory holding Project.toml).
  • migrate — also convert the test baselines and a former seed_defects.py, and write .gbg/scratch/commit-message.txt for the migration commit.
  • dry_run — print what would be written, write nothing.
  • io — where the report goes.

It writes .gbg/config.toml from the tree, an empty ledger, .gbg/rounds/.keep, a placeholder persona for every domain hat without one, the seeded-once files that are absent (test/Project.toml, docs/make.jl, test/runtests.jl, test/regressions/, docs/ROADMAP.md, docs/prose_shape.csv), and the tool's entries into docs/, test/ and every sub-environment that lists the tool. It refuses an existing .gbg/config.toml (exit 2). Returns the exit code.

source
GBGCodingTools.Init.migrate_baselines — Function
migrate_baselines(root = pwd(); dry_run = false, io = stdout) -> Int

gbg migrate baselines: the textual converter from the consumer's existing test files to the three frozen TOML baselines TestHarness reads. The arguments are root, the package root; dry_run, print the TOML instead of writing it; and io, where the report goes.

The .jl files are read, never included or edited. A literal not found is reported and skipped (exit 0); a literal that does not parse to its closing paren is exit 2 naming the line; an existing TOML is refused (exit 2) unless dry_run. Returns the exit code.

source
GBGCodingTools.Init.migrate_seeds — Function
migrate_seeds(root, cfg; io = stdout) -> Int

Converts a former .claude/commands/check-consistency/seed_defects.py CATALOG (tuples of class, description, anchor regex, replacement, occurrence) into .gbg/seeds.toml as the seeds definition states. The arguments are root, the package root; cfg, the derived config (for the package name); and io, where the report goes. An absent source writes nothing, exit 0; an existing seeds.toml is left alone. Returns the exit code.

source
GBGCodingTools.Init.new — Function
new(pkgname; parent = pwd(), io = stdout) -> Int

gbg new <Pkg>: init for a fifth package. The arguments are pkgname, the package name; parent, the directory holding the package (or the package root itself); and io, where the report goes.

The package tree must already exist with a Project.toml. Besides init, it seeds CLAUDE.md from the skeleton and adds a [[consumer]] row to the dev checkout's fleet.toml. Returns the exit code.

source
GBGCodingTools.Sync.sync — Function
sync(cfg; check = false, io = stdout, ledger = Ledger.read(cfg)) -> Int

gbg sync [--check]. The arguments are cfg, the validated config; check, compare only, write nothing; io, where the status lines go; and ledger, the ledger entries.

It renders every managed file and block, seeds .claude/WORK_QUEUE.md when absent, writes the tool's entries into every sub-environment Project.toml that lists it, inserts the CI fragments, and rewrites .gbg/managed.json; idempotent. It refuses (exit 2) on a MODIFIED or UNMANAGED file and writes nothing then. With check = true the exit is 1 when anything would change, else 0. Returns the exit code.

source
GBGCodingTools.cmd_config — Function
cmd_config(args) -> Int

gbg config --toml|--json [--effective]: prints the validated config with every default materialised — the object Config.read() returns in-process. --toml (the default) prints TOML, --json prints JSON; --effective adds the machine facts read at run time (hostname, Threads.nthreads(), the Julia version and the running tool version) under a [effective] table. Returns 0, or 2 when the config cannot be read (the reason is printed to stderr).

source
GBGCodingTools.cmd_schema — Function
cmd_schema(args) -> Int

gbg schema <name>: prints schema/<name>.schema.json of the running copy with its defaults, as JSON. Returns 0; an unknown name lists the available schemas to stderr and returns 2.

Checks and scans

GBGCodingTools.Doctor.run — Function
run(cfg; only = nothing, deep = false, io = stdout, json = false, effective = false) -> (checks, code)

Runs the selected checks over a consumer and prints the table. The arguments are:

  • cfg — the validated config.
  • only — ids, id prefixes or the literal QUICK to restrict the run to; every non-deep check when nothing.
  • deep — include the --deep checks (they run builds, tests and witnesses).
  • io — where the report goes.
  • json — print the results as JSON instead of the table.
  • effective — print the effective config after the table.

A FAIL on an exemptable id that a live scope = "check" ledger entry names becomes a WARN carrying the entry's reason. Returns the results and the exit code: 1 on any FAIL, else 0.

source
GBGCodingTools.doctor — Function
doctor(cfg, set = :QUICK; io = stderr) -> Int

The in-process doctor the makedocs wrapper, TestHarness.gate() and gbg preflight call. The arguments are cfg, the validated config; set, :QUICK for the quick set or :ALL for every non-deep check; and io, where the failing lines are printed. Returns 1 on any FAIL, else 0.

source
GBGCodingTools.scan_docs — Function
scan_docs(cfg; hard_only = false, only = nothing, io = stdout) -> (results, code)

Runs every catalogued text scan (and the consumer's [[scans.custom]] rows) over the source surfaces and prints the full report: every hard hit and every triage hit, never truncated. The arguments are:

  • cfg — the validated config.
  • hard_only — run the hard tier alone (what makedocs calls).
  • only — a list of ids or id prefixes to restrict the run to.
  • io — where the report goes.

The exit code follows the contract: 2 when any scan is DEAD (measured nothing, or raised), else 1 when any hard scan has a hit, else 0; triage hits never change it. Returns the results and the code.

source
GBGCodingTools.scan_html — Function
scan_html(cfg, build_dir; only = nothing, io = stdout) -> (results, code)

Runs the built-HTML scans (runner = "html") over the pages under build_dir through the Gumbo walker, applies the ledger and prints the report. The arguments are:

  • cfg — the validated config.
  • build_dir — the Documenter build directory.
  • only — a list of ids or id prefixes to restrict the run to.
  • io — where the report goes.

A missing or empty build is DEAD, exit 2. SCAN.HTML_PUBLIC_HOME reads .gbg/scratch/public_surface.json, which write_public_surface writes before the build. Returns the results and the exit code as scan_docs does.

source
GBGCodingTools.write_public_surface — Function
write_public_surface(cfg; pkg = Reflection.load_package(cfg)) -> String

Writes .gbg/scratch/public_surface.json: the package's exported names and the public operations Reflection.package_operations derives (every function with a method in a package module), so the built-HTML scan SCAN.HTML_PUBLIC_HOME can ask whether each has a public home. The arguments are cfg, the validated config, and pkg, the loaded package module (loaded from the config when not given). Returns the path.

source
GBGCodingTools.gate — Function
gate(cfg, instruments...; io = stderr) -> Int

The closure gate (§6.2 step 10). The arguments are cfg, the validated config; instruments, the instruments whose open rounds block (all four when none is named); and io, where the refusal is explained.

It scans EVERY round directory under .gbg/rounds/. An open round of a named instrument is exit 1, naming it — except the rounds named in GBG_ROUND (comma separated), which the CLI exports only while it runs a build, a test or an executable claim on behalf of that round. An open round of a disabled instrument is exit 1 (CFG.VALID).

In a working tree (no CI variable) an open round whose directory is untracked or modified while HEAD ≠ ROUND.head is exit 1: the fixes were committed without the round. A round directory without ROUND.toml is exit 2; .gbg/rounds/ absent while instruments are enabled is exit 2 (ROUND.DIR). gbg self verify runs first and its exit 2 is the gate's. Closed rounds are never re-graded here. Returns the code.

Rounds

GBGCodingTools.Preflight.preflight — Function
preflight(cfg, instrument; profile = nothing, hats = String[], strength = "economy", no_seed = false, dry = false, base = nothing, io = stdout) -> Int

gbg preflight <instrument> [--profile all|core|explicit] [--hats a,b] [--strength full] [--no-seed] [--dry] [--base <commit>]. The arguments are:

  • cfg — the validated config.
  • instrument — one of the four instruments.
  • profile — the check-consistency profile (all, core, explicit); the config's when nothing.
  • hats — the keys an explicit profile names.
  • strength — economy (the default) or full.
  • no_seed — open an unseeded check-consistency round.
  • dry — open and write nothing; print the round id and paths that would be used.
  • base — the audit's base commit (required for audit-changes).
  • io — where the protocol, the call and the next step are printed.

It runs the quick doctor, CFG.TORN and gbg self verify; refuses (exit 2) an open round of this instrument or an uncommitted change under a closed or abandoned round; opens the round (writes ROUND.toml, never git add); copies the scripts and writes the payloads; prints the protocol, the Workflow call and the next step. Returns the exit code.

source
GBGCodingTools.Rounds.prepare — Function
prepare(cfg, round; io = stdout) -> Int

gbg round prepare <round>, by instrument. The arguments are cfg, the validated config; round, the round id; and io, where the report goes.

check-consistency: the docs build under GBG_ROUND (exit 0 required; the log path is printed otherwise), the two manuscripts consolidated into the payload directory, and — when the round is seeded — the seeds planted in place (ground truth NOT written). check-docs: scan docs with every hard hit banked as lane 00-scans, the reflection checks, the build under GBG_ROUND, scan html (its hard hits banked too), the full report saved. audit-changes: the diff, diffstat and claims regenerated. bug-hunt: nothing to prepare. Returns the exit code.

build(cfg, round; io = stdout) -> Int

GBGCodingTools.Rounds.bank — Function
bank(cfg, round; io = stdout) -> Int

gbg round bank <round>. The arguments are cfg, the validated config; round, the round id; and io, where the classification and the recall are printed.

It validates every expected lane file, records each classified file's sha at first sight (lane_shas; a DEAD lane's file is not recorded, and Rounds.rerun forgets the sha of a lane it re-runs), classifies (DEAD, REJECTED, EMPTY, TRUNCATED), assigns ids <round>/<lane>#<n>; for a seeded round regenerates the unseeded manuscripts, recomputes the ground truth, marks seeded findings, prints recall per class and SUSPECT hats; for a hunt runs the witness runner over witnesses/ expecting failure and freezes the disposition records; writes findings.json and findings_sha, findings.md and SUMMARY.md. Any DEAD lane ⇒ exit 2 and nothing frozen (lane_shas stays). Returns the exit code.

source
GBGCodingTools.Rounds.rerun — Function
rerun(cfg, round, lanes; io = stdout) -> Int

gbg round rerun <round> --lanes a,b: prints the instrument's Workflow call restricted to the lanes the last bank classified DEAD. The arguments are cfg, the validated config; round, the round id; lanes, the lane keys; and io, where the call is printed. A live lane is refused; the first-sight sha of each named lane is forgotten, since the re-run replaces its file. Returns the exit code.

source
GBGCodingTools.Passes.pass_open — Function
pass_open(cfg, round; regrade = false, io = stdout) -> Int

gbg round pass open <round> [--regrade]: opens a verification pass. The arguments are:

  • cfg — the validated config.
  • round — the round id.
  • regrade — accept a changed stamp (config_sha, or the tool stamps) and re-stamp it; the round is re-graded from here, and the pass records regrade = true.
  • io — where the calls and messages are printed.

It refuses a changed config_sha unless regrade; creates verdicts/pass-<k>/pass.toml with the nonce, head, range = <opening head>..HEAD, the expected verdict count per lane and the stamps; for the doc instruments rebuilds under GBG_ROUND and regenerates the manuscripts; writes the findings' unabridged text as a payload file; prints the verifiers' Workflow calls rendered by Preflight's renderer. Returns the exit code.

source
GBGCodingTools.Passes.grade — Function
grade(cfg, round; io = stdout) -> Int

gbg round grade <round>: grades the latest pass. The arguments are cfg, the validated config; round, the round id; and io, where the tally lines are printed.

It validates the pass's verdict files (a wrong nonce or sha is REJECTED, an absent file with a non-zero expectation is DEAD ⇒ exit 2), applies the demotion, then the closure channels per id — honored, adjudicated, seeded, rescan; for a hunt the disposition records and the witness re-run; for an audit the disposition gate after the severity re-check — and writes tally.json and tally.md with the pass series and the plateau signal. Exit 1 while open_ids is non-empty, 0 when every id is closed.

source
GBGCodingTools.Passes.close — Function
close(cfg, round; io = stdout) -> Int

gbg round close <round>: checks every closing condition in the instrument's order and stamps the round closed. The arguments are cfg, the validated config; round, the round id; and io, where the refusals are listed.

The conditions (§6.2 step 9; §6.7 for the hunt; §6.8 for the audit): the latest pass fully closed, no dead lane, the round's files committed, the stamps unchanged (tool version and config, else regrade; tool tree sha, else abandon-only), the opening head an ancestor of HEAD, the dismissal auditor run over every adjudication and refusal with reopened == [] (its Workflow call is printed when it has not run), the hunt's witness, promotion, test and audit conditions. Then closed, closed_head and the tally sha are stamped. Returns 0 when closed, 1 when a condition is unmet, 2 on a stamp mismatch.

GBGCodingTools.Rounds.abandon — Function
abandon(cfg, round, reason; io = stdout) -> Int

gbg round abandon <round> --reason "…": the only wholesale exit. It writes abandoned = {reason, open_ids} with every id still open (all banked ids when no pass was graded). Returns 0.

GBGCodingTools.audit_bank — Function
audit_bank(cfg, round; io = stdout) -> Int

gbg audit-changes bank <round>: the audit's bank runs the executable claims itself, then the generic bank. The arguments are:

  • cfg — the validated config.
  • round — the round id (<date>-<instrument>-<NN>).
  • io — where the report goes.

It runs package.julia_test (the gate claim) and every file named under executable_claims with GBG_ROUND exported, records {command, file, exit, log} in audit.json together with base, head, kind and the covered paths, then runs Rounds.bank; afterwards it prints the severity re-check Workflow call (an anchor, before "serious" is counted at grade). Returns the bank's exit code.

Fleet and release

GBGCodingTools.Fleet — Module
Fleet

The fleet scorecard: Fleet.rows computes one row per consumer of fleet.toml — OK, NOT-INITIALISED, BEHIND or RED with a detail — and Fleet.diff prints two closed rounds' tallies side by side. The exit contract is D4's: 0 when every row is OK; 1 on NOT-INITIALISED, RED, or BEHIND outside the 7-day sweep window; 2 when a listed path does not exist.

source
GBGCodingTools.Fleet.latest_tag — Function
latest_tag(root) -> Union{VersionNumber,Nothing}

The newest released vX.Y.Z tag of the repository at root (prereleases excluded), or nothing.

source
GBGCodingTools.Fleet.rows — Function
Fleet.rows(; deep = false) -> (rows, code)

One row per [[consumer]]: (name, pin, status, detail). A consumer without .gbg/config.toml is NOT-INITIALISED; one whose QUICK doctor (the full non-deep set with deep) fails is RED with the failing ids; one whose pinned version is older than the fleet's newest is BEHIND with both versions and the window state; else OK. The tool's own row (path = ".") shows dev+<sha>[-dirty] with clean at vX.Y.Z or off tag, is OK/RED by its own doctor and never BEHIND. A missing path is exit 2. Returns the rows and the exit code.

source
GBGCodingTools.Fleet.diff — Function
Fleet.diff(a, b; io = stdout) -> Int

gbg fleet --diff <consumer>:<round> <consumer>:<round>: two closed rounds' tallies side by side. The arguments are a and b, each <consumer>:<round> naming a consumer of fleet.toml and a closed round of it, and io, where the table is printed.

The table holds the totals, the closure channels, the demotions, the adjudicated share and the recall. Rounds whose tool versions differ in MAJOR.MINOR are refused (exit 2), since their rates are not comparable. Returns the exit code.

GBGCodingTools.bump — Function
bump(cfg, ver; abandon = nothing, io = stdout) -> Int

Moves the pinned version of the consumer at cfg["root"] to ver (a released X.Y.Z), refusing (exit 2) while a round is open unless abandon gives the reason every open round is abandoned with; rewrites the [tool] version line of .gbg/config.toml, runs sync (which re-renders every managed file and the sub-environment entries), writes .gbg/scratch/bump-message.txt from the template, and records the [sweep] window in the dev checkout's fleet.toml when the bump leaves the fleet at two versions. The arguments are cfg, the validated config; ver, the target version; abandon, the abandon reason or nothing; and io, where the report goes. Returns the exit code.

GBGCodingTools.release — Function
release(ver; io = stdout, skip_tests = false) -> Int

Tags and pushes v<ver> from the dev checkout. The arguments are ver, X.Y.Z or X.Y.Z-rc.N; io, where the checks are reported; and skip_tests, for the self-tests of this verb only (never set by the CLI).

Refused (exit 2) unless: the tree is clean and on the configured branch; the tag is absent; CHANGELOG.md carries ## <ver> —; Project.toml's version equals the release version (the base version for a prerelease); Pkg.test() is green; the tool's own docs build exits 0 (SELF.DOCS); gbg doctor --deep is green at the root; and, for a final release only, no round is open under .gbg/rounds/ and the /check-docs round opened at the latest <ver>-rc.<n> tag is closed by honored or adjudicated ids. A tag is never moved or re-issued. Returns the exit code.

GBGCodingTools.selftest — Function
selftest(; pinned = false, io = stdout) -> Int

Runs the running copy's own Pkg.test() from a temporary environment that develops it by path, so the arms of §8 run over the fixture wherever the tool is installed. With pinned, additionally copies the fixture to ${TMPDIR}/gbg-pinned-fixture/, pins it at the newest released tag (its sub-environment sources rewritten to the https url and rev), instantiates its docs/ environment and runs the QUICK doctor there — the pinned-copy behaviours (PIN.SELF, PIN.TREESHA, PIN.SOURCES) — leaving the copy in place for the install phase. The arguments are pinned and io, where the report goes. Returns the exit code.
