The verbs

Written by AI, not regularly reviewed

This page is written by AI and is not reviewed regularly by a human.

gbg <noun> <verb> is the whole command line; the table is closed, and every verb below is rendered from its own docstring so the page cannot drift from the code. The exit contract is one for all: 0 clean, 1 a substantive finding, 2 cannot evaluate (a precondition not met, missing input, torn file), 3 crash.

Entry point

GBGCodingTools.main — Function
main(args) -> Int

The one entry point of the command line: the shim execs julia -e 'using GBGCodingTools; exit(GBGCodingTools.main(ARGS))', and every test of a verb calls it directly. Dispatches <noun> <verb> (or a lone noun) through VERBS and returns that function's exit code: 0 clean, 1 substantive finding, 2 cannot evaluate, 3 crash. A --dev first argument sets GBG_DEV=1 so the stamps read dev+<sha>, exactly as the shim's --dev route does. An unknown verb prints the table and returns 2. Output is never truncated.

An exception escaping a verb is printed with its backtrace to stderr and returns 3, so a crash is never read as a finding. The exceptions are the consumer's own files failing to read or validate — a Config.ConfigError or a Ledger.LedgerError — the documented exit 2, printed without a backtrace. A config the verb has itself just written failing to read back is not that case; it raises Config.ConfigWrittenError and returns 3.

GBGCodingTools.parse_options — Function
parse_options(args; valued = String[]) -> Options

Parses args into an Options record. Any --name=value is a value whatever valued says; an option named in valued also consumes the following bare argument as its value; every other bare --name is a flag; a lone -- ends option parsing. The arguments are:

  • args — the command-line arguments to parse, in order.
  • valued — the names, without the dashes, of the options that take a value.

Returns the parsed options; an option that is in valued but has no value is an ArgumentError.

source
GBGCodingTools.Options — Type
Options

The parsed command line of one verb: the positional arguments in order and the options by name.

The fields are:

  • positional — every argument that is not an option, in order.
  • flags — the options given without a value (--deep, --dry-run), as a set of names without the dashes.
  • values — the options given with a value (--only LOAD, --reason "…", --profile=core), name to value.

Machine and self

GBGCodingTools.cmd_install — Function
cmd_install(args) -> Int

gbg install [--dev-checkout <path>]: copies the running copy's bin/gbg to ~/.local/bin/gbg with mode 755 and, with the option, writes the one-line pointer ~/.gbg/dev. Runs from whichever copy Pkg resolved for the calling environment — no depot glob is ever expanded. Returns 0 when the shim is written, and the ~/.gbg/dev pointer with it under --dev-checkout, 2 when the Julia in use is below the floor, when --dev-checkout names a directory that is not a GBGCodingTools checkout, or when ~/.local/bin is not on PATH (the shim would be installed but never found).

GBGCodingTools.self_verify — Function
self_verify(root = Config.find_root(); io = stdout) -> Int

Recomputes the git tree hash of the copy this process runs from (pkgdir(GBGCodingTools), through TreeHash.tree_hash) and compares it with what Pkg.dependencies() reports for the tool in the active environment and with the git-tree-sha1 every sub-environment manifest under root records; asserts the dependency entry is is_tracking_repo && !is_tracking_path (a Pkg.develop'd copy lives inside the depot, so only the flags tell it apart). The arguments are:

  • root — the consumer root whose sub-environment manifests are compared; nothing (no root found) leaves only the active environment's entry to compare against.
  • io — where the one line per comparison is printed.

Returns 0 when every comparison agrees, 0 with a WARN when the running copy is a working tree (pinned at dev) or no manifest exists to compare against, and 2 for a disagreement or a developed copy — an edited pinned tree is never allowed to grade a round.

source
GBGCodingTools.cmd_self_verify — Function
cmd_self_verify(args) -> Int

gbg self verify: the command-line face of self_verify; run by every gbg round verb and by gbg gate before anything else. Returns its code: 0, or 2 for an edited or developed pinned copy.

GBGCodingTools.cmd_probe — Function
cmd_probe(args) -> Int

gbg probe [--fail]: exists for the platform verification V2 and nothing else. Prints PROBE OK and returns 0; with --fail prints PROBE FAIL to stderr and returns 2. Reads and writes no file.

Consumer setup

GBGCodingTools.Init.init — Function
init(root = pwd(); migrate = false, dry_run = false, io = stdout) -> Int

gbg init [--migrate] [--dry-run]: seeds a consumer. The arguments are:

  • root — the package root (the directory holding Project.toml).
  • migrate — also convert the test baselines and a former seed_defects.py, and write .gbg/scratch/commit-message.txt for the migration commit.
  • dry_run — print what would be written, write nothing.
  • io — where the report goes.

It writes .gbg/config.toml from the tree, an empty ledger, .gbg/rounds/.keep, a placeholder persona for every domain hat without one (Preflight.resolve_hats binds the term), the seeded-once files that are absent (test/Project.toml, docs/make.jl, test/runtests.jl, test/regressions/, docs/ROADMAP.md, docs/prose_shape.csv), and the tool's entries into docs/, test/ and every sub-environment that lists the tool. It refuses an existing .gbg/config.toml (exit 2) unless dry_run, which previews over one rather than refusing, a preview writing nothing. Returns the exit code.

source
GBGCodingTools.Init.migrate_baselines — Function
migrate_baselines(root = pwd(); dry_run = false, io = stdout) -> Int

gbg migrate baselines: the textual converter from the consumer's existing test files to the three frozen TOML baselines TestHarness reads. The arguments are:

  • root — the package root.
  • dry_run — print the TOML instead of writing it.
  • io — where the report goes.

The .jl files are read, never included or edited. A literal not found is reported and skipped (exit 0); a literal that does not parse to its closing paren is exit 2 naming the line; an existing TOML is refused (exit 2) unless dry_run. Returns the exit code.

source
GBGCodingTools.Init.new — Function
new(pkgname; parent = pwd(), io = stdout) -> Int

gbg new <Pkg>: init for a fifth package. The arguments are:

  • pkgname — the package name.
  • parent — the directory holding the package (or the package root itself).
  • io — where the report goes.

The package tree must already exist with a Project.toml. Besides init, it seeds CLAUDE.md from the skeleton and adds a [[consumer]] row to the dev checkout's fleet.toml. Returns the exit code.

source
GBGCodingTools.Sync.sync — Function
sync(cfg; check = false, io = stdout, ledger = Ledger.read(cfg)) -> Int

gbg sync [--check]. The arguments are:

  • cfg — the validated config.
  • check — compare only, write nothing.
  • io — where the status lines go.
  • ledger — the ledger entries.

It renders every managed file and block, seeds .claude/WORK_QUEUE.md when absent, writes the tool's entries into every sub-environment Project.toml that lists it, inserts the CI fragments, and rewrites .gbg/managed.json; idempotent. It refuses (exit 2) on a MODIFIED or UNMANAGED file and writes nothing then. With check = true the exit is 1 when anything would change, else 0. Returns the exit code.

source
GBGCodingTools.Sync.cmd_sync — Function
cmd_sync(args) -> Int

gbg sync [--check]: the CLI face of Sync.sync over the config found from the working directory. Returns the exit code.

source
GBGCodingTools.cmd_config — Function
cmd_config(args) -> Int

gbg config --toml|--json [--effective]: prints the validated config with every default materialised — the object Config.read() returns in-process. --toml (the default) prints TOML, --json prints JSON; --effective adds the machine facts read at run time (hostname, Threads.nthreads(), the Julia version and the running tool version) under a [effective] table. Returns 0, or 2 when the config cannot be read (the reason is printed to stderr).

source
GBGCodingTools.cmd_schema — Function
cmd_schema(args) -> Int

gbg schema <name>: prints schema/<name>.schema.json of the running copy with its defaults, as JSON. Returns 0; an unknown name lists the available schemas to stderr and returns 2.

Checks and scans

GBGCodingTools.Doctor.run — Function
run(cfg; only = nothing, deep = false, io = stdout, json = false,
    effective = false) -> (checks, code)

Runs the selected checks over a consumer and prints the table. The arguments are:

  • cfg — the validated config.
  • only — ids, id prefixes or the literal QUICK to restrict the run to; every non-deep check when nothing.
  • deep — include the --deep checks (they run builds, tests and witnesses).
  • io — where the report goes.
  • json — print the results as JSON instead of the table.
  • effective — print the effective config after the table.

A FAIL on an exemptable id that a live scope = "check" ledger entry names becomes a WARN carrying the entry's reason. Returns the results and the exit code: 1 on any FAIL, else 0.

source
GBGCodingTools.Doctor.cmd_doctor — Function
cmd_doctor(args) -> Int

gbg doctor [--deep] [--json] [--effective] [--only <id-or-prefix>[,…]|QUICK]: exit 2 when the working directory is not a consumer (no valid .gbg/config.toml), else the run's code. Returns it.

GBGCodingTools.doctor — Function
doctor(cfg, set = :QUICK; io = stderr) -> Int

The in-process doctor the makedocs wrapper calls. The arguments are:

  • cfg — the validated config.
  • set — :QUICK for the quick set, :ALL for every non-deep check.
  • io — where the failing lines are printed.

Returns 1 on any FAIL, else 0.

GBGCodingTools.cmd_scan — Function
cmd_scan(args) -> Int

gbg scan docs [--hard-only] [--only id,…] [--rebaseline prose-shape --reason "…"] and gbg scan html <build_dir>: the CLI face of scan_docs and scan_html. Returns the scan exit code; a rebaseline first prints every row it raises, adds or drops (the rule's own changes), then writes docs/prose_shape.csv and returns 0.

source
GBGCodingTools.scan_docs — Function
scan_docs(cfg; hard_only = false, only = nothing, io = stdout) -> (results, code)

Runs every catalogued text scan (and the consumer's [[scans.custom]] rows) over the source surfaces and prints the full report: every hard hit and every triage hit, never truncated. The arguments are:

  • cfg — the validated config.
  • hard_only — run the hard tier alone (what makedocs calls).
  • only — a list of ids or id prefixes to restrict the run to.
  • io — where the report goes.

The exit code follows the contract: 2 when any scan is DEAD (measured nothing, or raised), else 1 when any hard scan has a hit, else 0; triage hits never change it. Returns the results and the code.

source
GBGCodingTools.scan_html — Function
scan_html(cfg, build_dir; only = nothing, io = stdout) -> (results, code)

Runs the built-HTML scans (runner = "html") over the pages under build_dir through the Gumbo walker, applies the ledger and prints the report. The arguments are:

  • cfg — the validated config.
  • build_dir — the Documenter build directory.
  • only — a list of ids or id prefixes to restrict the run to.
  • io — where the report goes.

A missing or empty build is DEAD, exit 2. Returns the results and the exit code as scan_docs does.

source
GBGCodingTools.write_public_surface — Function
write_public_surface(cfg; pkg = Reflection.load_package(cfg)) -> String

Writes .gbg/scratch/public_surface.json: the package's exported names and the public operations Reflection.package_operations derives (every function with a method in a package module), so the a check can ask whether each has a public home. The arguments are:

  • cfg — the validated config.
  • pkg — the loaded package module (loaded from the config when not given).

Returns the path.

Fleet and release

GBGCodingTools.Fleet — Module
Fleet

The fleet scorecard: Fleet.rows computes one row per consumer of fleet.toml — OK, NOT-INITIALISED, BEHIND or RED with a detail. The exit contract is D4's: 0 when every row is OK; 1 on NOT-INITIALISED, RED, or BEHIND outside the 7-day sweep window; 2 when a listed path does not exist.

source
GBGCodingTools.Fleet.latest_tag — Function
latest_tag(root) -> Union{VersionNumber,Nothing}

The newest released vX.Y.Z tag of the repository at root (prereleases excluded), or nothing.

source
GBGCodingTools.Fleet.rows — Function
Fleet.rows(; deep = false) -> (rows, code)

One row per [[consumer]]: (name, pin, status, detail). A consumer without .gbg/config.toml is NOT-INITIALISED; one whose QUICK doctor fails is RED with the failing ids; one whose pinned version is older than the fleet's newest is BEHIND with both versions and the window state; else OK. The tool's own row (path = ".") shows dev+<sha>[-dirty] with clean at vX.Y.Z or off tag, is OK/RED by its own doctor and never BEHIND. A missing path is exit 2. The arguments are:

  • deep — run every check, the --deep ones included, as each consumer's doctor pass instead of the QUICK set.

Returns the rows and the exit code.

source
GBGCodingTools.bump — Function
bump(cfg, ver; io = stdout) -> Int

Moves the pinned version of the consumer at cfg["root"] to ver (a released X.Y.Z); rewrites the [tool] version line of .gbg/config.toml, runs sync (which re-renders every managed file and the sub-environment entries), writes .gbg/scratch/bump-message.txt from the template, and records the [sweep] window in the dev checkout's fleet.toml when the bump leaves the fleet at two versions. The arguments are:

  • cfg — the validated config.
  • ver — the target version.
  • io — where the report goes.

Returns the exit code.

GBGCodingTools.release — Function
release(ver; io = stdout, skip_tests = false, root = pkgdir(GBGCodingTools)) -> Int

Tags and pushes v<ver> from the dev checkout. The arguments are:

  • ver — the version to tag, X.Y.Z or X.Y.Z-rc.N.

  • io — where the checks are reported.

  • skip_tests — skips Pkg.test(), the docs build and the deep doctor; for the self-tests of this verb only, never set by the CLI.

  • root — the checkout to release, the running package directory by default; the CLI never passes it. A keyword because the verb read pkgdir(GBGCodingTools) directly and so had no test at all. Every refusal below reads root, the dev-checkout guard included: root must be a git working tree, since it is what gets tagged and pushed.

Refused (exit 2) unless: the tree is clean and on the configured branch; the tag is absent; CHANGELOG.md carries ## <ver> —; Project.toml's version equals the release version (the base version for a prerelease); Pkg.test() is green; the tool's own docs build exits 0 (SELF.DOCS); gbg doctor --deep is green at the root. Nothing else holds a release — no review, no open finding, no unanswered question, no audit. A tag is never moved or re-issued. Returns the exit code.

source
GBGCodingTools.selftest — Function
selftest(; pinned = false, io = stdout) -> Int

Runs the running copy's own Pkg.test() from a temporary environment that develops it by path, so the self-test's arms run over the fixture wherever the tool is installed. With pinned, additionally copies the fixture to ${TMPDIR}/gbg-pinned-fixture/, pins it at the newest released tag (its sub-environment sources rewritten to the https url and rev), instantiates its docs/ environment and runs the QUICK doctor there — the pinned-copy behaviours (PIN.SELF, PIN.TREESHA, PIN.SOURCES) — leaving the copy in place for the install phase. The arguments are:

  • pinned — also runs the pinned-copy arm described above; false stops after the Pkg.test() run.
  • io — where the report and the child processes' output go.

Returns the exit code.
