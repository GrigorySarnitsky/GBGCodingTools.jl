GBGCodingTools.Catalogue — Module
Catalogue

What this package knows, as values rather than as files: the always-on checks, the instruments, the rulebook, and the readers derived from it.

It is the third module of the order and holds DATA — a rule sits here beside the check that decides it, and nothing here runs anything: the instrument table, the rulebook as RULES, the retired rules, the fleet, and the reader derivation of the documentation review.

The table here and the one in the design are compared cell by cell by test/architecture.jl: a row whose purpose, intention, decider, fixer, timing or ending drifts from the document fails the suite, so the document and the code cannot quietly disagree about what an instrument is for.

GBGCodingTools.Catalogue.ALWAYS_ON — Constant
ALWAYS_ON

The checks every build and every test runs. Nobody starts one, none of them has a run, and what one finds is fixed by whoever ran the build or the test as part of the work in hand.

source
GBGCodingTools.Catalogue.INSTRUMENTS — Constant
INSTRUMENTS

The review procedures the owner starts, in words or by slash command. Each carries the three values that separate it from every other — what its defects are in, what decides that a finding is real, and who fixes what it found — and the two sentences the table prints.

The roles each launches are empty here and are filled in the phase that builds that instrument; the leak scan is not here at all, because the design marks its row future.

source
GBGCodingTools.Catalogue.RULES — Constant
RULES

The rulebook: every rule as a value, beside the check that decides it and the examples that show the check matches the statement, one file of src/Rules/ per family. The rulebook a session loads, .gbg/policy/, is rendered from these values and never edited.

GBGCodingTools.Catalogue.axes — Function
axes(x) -> Tuple

The three values that separate one check or instrument from every other: what its defects are in, what decides that a finding is real, and who fixes what it found. The argument is x, an Model.AlwaysOn or an Model.Instrument. Returns the three, in that order.

source
GBGCodingTools.Catalogue.doc — Function
doc(r::Rule) -> String
doc(role::AgentRole) -> String
doc(i::Instrument) -> String
doc(a::AlwaysOn) -> String

The docstring of a rule, an agent role, an instrument or an always-on check, written from the value itself. A rule's prose is written once, in the value, and the docstring a reader sees on the package's own site is derived from it — so the two cannot disagree, and a rule reworded in one place is reworded in both.

The argument is the value to describe. Returns the docstring text, which the source attaches with @doc doc(x) x.

GBGCodingTools.Catalogue.known_ids — Function
known_ids() -> Set{Symbol}

Every id a package's config may name in a switch: each rule of the rulebook, each agent role of each instrument, and each instrument. Returns the set.

The rule with that id, or nothing where the rulebook holds none. The argument is id, the rule's identifier. Returns the rule.
