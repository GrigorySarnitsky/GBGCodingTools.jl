GBGCodingTools.Witnesses — Module
Witnesses

The witness runner of /bug-hunt. A witness is a self-contained Julia file asserting the CORRECT behaviour of the package, so it FAILS on a defective tree and PASSES once the defect is fixed; Witnesses.run executes every witness of a directory in a fresh process and holds the set to one expectation, reporting each file as a WitnessResult. The directory is usually a round's — a round being one run of one instrument (GBGCodingTools binds the term) over one consumer, recorded as a tracked directory under .gbg/rounds/. An agent's account of a program that fails is not that program; this is.

GBGCodingTools.Witnesses.WitnessResult — Type
WitnessResult

The outcome of one witness file.

The fields are:

  • name — the file name.
  • status — :pass, :fail (an assertion came out false — the witness working), :broken (an exception outside an assertion, a load error, or a pass with zero assertions — evidence of nothing), :blocked (the file declares # blocked: <reason>, reported its counts, errored and failed nothing; a run that reported no counts is :broken) or :refused (the file loads something it may not, or includes a file — never run).
  • passes, fails, errors — the Test counts the run reported (zeros when it did not get that far).
  • reason — the blocked reason, the refusal, or the first lines of a broken run's output.

GBGCodingTools.Witnesses.run — Function
run(dir; expect, package, project, names = String[], io = stdout) -> (code, results)

Runs every witness under dir and holds the set to an expectation. The arguments are:

  • dir — the directory of .jl witnesses (the round's witnesses/, or test/regressions/escalated/).
  • expect — :fail (a hunt's bank: every witness must fail on this tree) or :pass (after the fix).
  • package — the package a witness may load.
  • project — the --project the witnesses run under.
  • names — restrict the run to the files whose names contain one of these.
  • io — where the per-witness lines and the summary go.

An empty directory is a refusal (nothing was verified), exit 2, as is any REFUSED witness. A witness that PASSES when failure was expected is a PHANTOM (the defect does not exist) and one that FAILS when a pass was expected is UNFIXED; either is exit 1. A BROKEN witness is exit 1 too — evidence of nothing in either direction. BLOCKED witnesses are reported apart and do not fail the run.

Returns the exit code and the per-witness results.
