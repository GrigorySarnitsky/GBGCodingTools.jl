GBGCodingTools.TestHarness — Module
TestHarness

The engines behind a consumer's test/: the allocation audit (@alloc_below, TestHarness.allocation_completeness and the operations it covers, TestHarness.AUDITED_ALLOCATION_OPS), the element-traffic audit (TestHarness.counting, TestHarness.CountingArray, TestHarness.Traffic, TestHarness.audit, TestHarness.traffic_completeness and the operations it covers, TestHarness.AUDITED_TRAFFIC_OPS), the method-parity baselines (TestHarness.method_parity), the oracle registry (TestHarness.oracle_registry), the display gate (TestHarness.display_gate), the cross-thread-count digest (TestHarness.thread_digest), seed parity across backends (TestHarness.seed_parity), device time against memory (TestHarness.device_cost), the promoted-witness loop (TestHarness.run_regressions). The tables a package freezes live in the consumer as TOML.

Allocation and traffic

GBGCodingTools.TestHarness.@alloc_below — Macro
@alloc_below bound expr

Asserts that one call of expr, after a warm-up, allocates fewer than bound bytes. A plain call is measured by allocated_call, compiled for its arguments' types, so a bound of one byte holds where nothing is allocated; building the arguments is not counted, and other expressions are measured in place. Each run evaluates the whole expression, arguments included. A thrown error fails the check. A plain call's callee is recorded in AUDITED_ALLOCATION_OPS.

GBGCodingTools.TestHarness.allocated_call — Function
allocated_call(f, args, kwargs) -> Int

The bytes one call f(args...; kwargs...) allocates, measured inside a function generated for the arguments' types, so that looking up a variable's type is not counted. @alloc_below measures a plain call through it, after running the call once to warm it up. The keywords arrive as a named tuple and are passed on as a keyword splat.

Arguments

  • f — the operation.
  • args — its positional arguments, a tuple.
  • kwargs — its keyword arguments, a named tuple.

Returns the count. The call is written out argument by argument, because a splat of more than 32 is applied dynamically and allocates; a test of a 33-operand sum met that. Its result is kept alive, so a returned array is counted. A type passed directly, as (Float64, x), is measured dynamically: the macro carries each type so the call is compiled for it.

GBGCodingTools.TestHarness.CountingArray — Type
CountingArray{T,N} <: AbstractArray{T,N}

A plain Array wrapper counting every getindex and setindex! with atomic counters, so an operation's element traffic can be measured through generic AbstractArray storage. A consumer using KernelAbstractions defines KernelAbstractions.get_backend(a::CountingArray) = get_backend(a.data) itself (the tool does not depend on it).

Fields

  • data — the wrapped array.
  • reads — the atomic read counter.
  • writes — the atomic write counter.

GBGCodingTools.TestHarness.Traffic — Type
Traffic

One array's row in an audited call.

Fields

  • role — the array's role in the call ("source", "dest", "kernel").
  • array — the CountingArray measured.
  • frozen — the (reads, writes) asserted exactly.

  • holder — the named holder REQUIRED when the two differ.

GBGCodingTools.TestHarness.audit — Function
audit(operation!, name, rows...; print = false)

One row of the traffic audit (the per-operation table of array reads and writes).

Arguments

  • operation! — a zero-argument closure running the operation once over the counting arrays.
  • name — the row's name; its leading token, up to whitespace, ( or ∘, is the operation recorded in AUDITED_TRAFFIC_OPS.
  • rows — one Traffic per array with its frozen (reads, writes).
  • print — print every measured count for re-baselining.

It zeroes the counters of every row, runs the operation, and asserts for every row that the measured pair equals the frozen pair exactly; a frozen count differing from its ideal must carry a named holder. Returns nothing.

GBGCodingTools.TestHarness.allocation_completeness — Function
allocation_completeness(pkg, modules; exempt = Dict{Symbol,String}())

The derived completeness check of the allocation audit.

Arguments

  • pkg — the package module.
  • modules — its owned modules (the public surface is derived from them).
  • exempt — operation name to reason, for the operations deliberately not audited.

Every exported in-place operation (a name ending in ! on the ownership-derived public surface) was exercised by @alloc_below, or is named in exempt with a reason; no exemption names a vanished operation; every recorded callee is a real package function. Runs as a @testset. Returns nothing.

Parity, oracles, display, threads

GBGCodingTools.TestHarness.method_parity — Function
method_parity(pkg, modules, baseline; externals = (Base,))

The method-parity engine.

Arguments

  • pkg — the umbrella module.
  • modules — the package modules.
  • baseline — the parsed test/method_parity_baseline.toml.
  • externals — the external modules whose generics the package extends.

Every [[generic]] entry {set, name, count, module} asserts the number of methods the named module defines for that generic, each set's total is asserted where the baseline states [set_total], the [module] table asserts the derived per-module counts, and detect_ambiguities over pkg must be empty. A moved number is reported with the instruction to refreeze deliberately, with the reason. Runs as a @testset. Returns nothing.

source
GBGCodingTools.TestHarness.oracle_registry — Function
oracle_registry(pkg, modules, registry, testdir)

The oracle-provenance engine.

Arguments

  • pkg — the umbrella module.
  • modules — the package modules.
  • registry — the parsed test/oracle_registry.toml ([[operation]] name, class, evidence).
  • testdir — the directory the cited test files live in.

Every public value-returning operation (the derived surface minus the ! names) is classified; no classification names a vanished operation; every class is one of analytic | independent | property | relational | structural; no operation rests on relational alone; and every non-structural citation names a test file under testdir that exists and mentions the operation. Runs as a @testset. Returns nothing.

GBGCodingTools.TestHarness.display_gate — Function
display_gate(modules; no_display = Dict{Symbol,String}, min_types = 1,
             falsify = true)

The display gate, DERIVED rather than listed: every concrete struct type has a package-owned show or an exemption with a reason.

Arguments

  • modules — the modules whose concrete struct types are enumerated.
  • no_display — type name to reason, for the types deliberately without a display; an exemption whose type has a show after all is stale (a widened blind spot), and one naming a type no longer defined is stale.
  • min_types — the least number of types the enumeration must find, so a parser that stops matching fails rather than reporting a clean sweep.
  • falsify — with true, an empty parametric struct is planted in the first module and must be enumerated without a display.

Runs as a @testset. Returns nothing.

thread_digest(probe_source; threads, project = Base.active_project()) -> String

Runs a probe in a fresh Julia process with a given thread count and returns its output — the cross-thread-count half of a bitwise-invariance check the in-process toggle cannot make.

GBGCodingTools.TestHarness.seed_parity — Function
seed_parity(draws, backends; seed = 1, other_seed = seed + 1, bound = 8)

The seed-parity contract, RULE.TEST.SEED_PARITY: one seed gives the same draws on every backend.

Arguments

  • draws — the package's function draws(seed, backend), as seed_measure reads it.
  • backends — the backends this machine can run, the CPU first; the package decides which work.
  • seed, other_seed — the seed, and the one a planted wrong run draws from.
  • bound — how far a transformed draw may differ, in machine epsilon.

An exact draw is bitwise equal on every backend, a transformed one within bound, and a run from other_seed is told apart on every draw. With one backend it records @test_skip and a warning: skipped, never passed, as on a runner with no GPU. Runs as a @testset. Returns what seed_measure measured, or nothing when skipped.

source
GBGCodingTools.TestHarness.seed_measure — Function
seed_measure(draws, backends; seed = 1, other_seed = seed + 1, bound = 8) -> NamedTuple

What seed_parity tests, measured without testing it.

Arguments

  • draws — the package's function draws(seed, backend), returning (exact = (; name => draw, …), rounded = (; name => draw, …)): the draws a run uses as drawn, and those it sees through a transform.
  • backends — the backends to compare, the reference first.
  • seed, other_seed — the seed, and the one the planted run draws from.
  • bound — how far a transformed draw may differ, in machine epsilon.

Returns (exact, rounded, planted, ok), per backend after the first: the exact draws not bitwise equal or not drawn by both, each transformed draw's distance, and, for every backend, the draws a run from other_seed failed to tell apart. The last, ok, holds when all is as the contract asks and two backends ran.

GBGCodingTools.TestHarness.seed_difference — Function
seed_difference(reference, other) -> Float64

How far two copies of one transformed draw are apart: the largest difference over the finite values, relative to the largest finite magnitude of reference, in machine epsilon of its element type. The arguments are the two draws, on any device, of one floating-point element type. Returns Inf where the types or shapes differ, or a non-finite value of one is not the same in the other.

source
GBGCodingTools.TestHarness.seed_identical — Function
seed_identical(a, b) -> Bool

Whether two copies of one exact draw are the same bits: the same element type, the same shape, and the same bytes — so -0.0 is not 0.0, a NaN equals itself, and a Float32 copy of a Float64 draw differs. The arguments are the two draws, on any device. Returns the answer.

GBGCodingTools.TestHarness.device_cost — Function
device_cost(cases, copy, sync; bounds = Dict(), reps = 30, warmup = 3)

The device-cost contract, RULE.TEST.DEVICE_COST: a device operation is timed against the memory it must move, and holds at or below the ratio its package froze for it.

Arguments

  • cases, copy, sync — as device_measure takes them; cases empty, as on a machine with no device, records a skip and never a pass.
  • bounds — the ratio frozen per operation's name, for the device and element type the run is on: the same operation costs a different ratio on another card or in another precision, so a package keeps one table for each. One with no bound is measured and reported, not judged, until its package freezes one from what it measured.
  • reps, warmup — as fastest takes them.

Runs as a @testset, and warns when the machine looked busy, since a timing then overstates the cost. Returns what device_measure measured, or nothing when skipped.

source
GBGCodingTools.TestHarness.device_measure — Function
device_measure(cases, copy, sync; reps = 30, warmup = 3) -> NamedTuple

What device_cost tests, measured without testing it: each operation's time against the time the device takes to move the memory it must move.

Arguments

  • cases — the operations: (name, run, bytes), run doing one call on the device and bytes the least memory it must read and write, which a traffic audit knows or a field's size gives.
  • copy — a copy on the same device, (run, bytes), whose rate is the bandwidth the ratios are taken against; measured in the same run, it moves with the clocks and the power limit.
  • sync — what waits until the device has finished.
  • reps, warmup — as fastest takes them.

Returns (bandwidth, rows, busy): the copy's bytes per second; per operation its name, its fastest time, its bytes and its ratio, the time over the time the bandwidth needs for the bytes; and whether the median runs ran half again over the fastest, a sign another load shared the device.

source
GBGCodingTools.TestHarness.fastest — Function
fastest(run, sync; reps = 30, warmup = 3) -> Tuple{Float64,Float64}

The fastest and the median wall time of one call of run, in seconds.

Arguments

  • run — the operation, called with no argument.
  • sync — what waits until the device has finished: a device runs asynchronously, and a clock read before it has finished times the launch, not the work.
  • reps, warmup — the timed calls, and the calls before them that compile and warm the caches.

Returns the two times. The fastest is the cost; the median beside it says how busy the machine was.

GBGCodingTools.TestHarness.run_regressions — Function
run_regressions(dir; parent = Main) -> Vector{String}

The one include loop of the promoted witnesses.

Arguments

  • dir — the consumer's test directory (@__DIR__ of runtests.jl); its regressions/ subdirectory is read, or dir itself when it is that directory.
  • parent — the module the wrapper modules are evaluated in.

Every *.jl directly under the regressions directory (sorted) is included into its own wrapper module Regression_<name>, so top-level helpers cannot collide across files. An empty directory is an honest state and runs nothing. Returns the list of files run.

The derived surface

GBGCodingTools.TestHarness.package_operations — Function
package_operations(pkg, modules) -> Set{Symbol}

The derived public surface: every exported function of the umbrella pkg and of its owned modules, plus every external generic a package module extends (found by walking the loaded modules and asking each function whether a package module owns one of its methods — a method defined under a qualified name creates no binding, so a namespace scan cannot see it). Internal helpers and closures never enter it. The arguments are pkg, the umbrella module, and modules, the owned modules. Returns the names. Harvested from Reflection.jl in Phase 5; the completeness checks below derive their required sets from it, so a new operation fails them until it is audited.

all_package_functions(pkg, modules) -> Set{Symbol}

Every function name a package module owns methods of, the umbrella's own and internal helpers included — the wider set a guard's own bookkeeping may name. Returns the set.
