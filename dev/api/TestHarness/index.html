TestHarness

GBGCodingTools.TestHarness — Module
TestHarness

The engines behind a consumer's test/: the allocation audit (@alloc_below and TestHarness.allocation_completeness), the element-traffic audit (TestHarness.CountingArray, TestHarness.Traffic, TestHarness.audit), the method-parity baselines (TestHarness.method_parity), the oracle registry (TestHarness.oracle_registry), the display gate (TestHarness.display_gate), the cross-thread-count digest (TestHarness.thread_digest), the promoted-witness loop (TestHarness.run_regressions) and the closure gate a suite ends with (TestHarness.gate). The frozen tables a package pins (method counts, traffic rows, oracle classes) live in the consumer as TOML; the engines here read them.

Allocation and traffic

GBGCodingTools.TestHarness.@alloc_below — Macro
@alloc_below bound expr

Warms expr up once (compilation, plans, first touch), then asserts a single call allocates strictly fewer than bound bytes. A thrown error becomes a failed test rather than aborting the testset, so one bad line cannot mask every check after it. The callee of expr (when it is a plain call) is recorded in AUDITED_ALLOCATION_OPS. Splice a NAMED function rather than an anonymous closure: the expression is evaluated twice and an anonymous closure would get two types, the second read as a compile allocation.

GBGCodingTools.TestHarness.CountingArray — Type
CountingArray{T,N} <: AbstractArray{T,N}

A plain Array wrapper counting every getindex and setindex! with atomic counters, so an operation's element traffic can be measured through generic AbstractArray storage. A consumer using KernelAbstractions defines KernelAbstractions.get_backend(a::CountingArray) = get_backend(a.data) itself (the tool does not depend on it).

The fields are:

  • data — the wrapped array.
  • reads — the atomic read counter.
  • writes — the atomic write counter.

GBGCodingTools.TestHarness.Traffic — Type
Traffic

One array's row in an audited call.

The fields are:

  • role — the array's role in the call ("source", "dest", "kernel").
  • array — the CountingArray measured.
  • frozen — the (reads, writes) asserted exactly.
  • ideal — the fused ideal documented beside it (each needed input element read once, each output written once).
  • holder — the named holder REQUIRED whenever frozen ≠ ideal.

GBGCodingTools.TestHarness.audit — Function
audit(operation!, name, rows::Traffic...; print = false)

One row of the traffic audit (the per-operation table of array reads and writes). The arguments are operation!, a zero-argument closure running the operation once over the counting arrays; name, the row's name (its leading token, up to whitespace, ( or ∘, is the operation recorded in AUDITED_TRAFFIC_OPS); rows, one Traffic per array with its frozen (reads, writes); and print, print every measured count for re-baselining.

It zeroes the counters of every row, runs the operation, and asserts for every row that the measured pair equals the frozen pair exactly; a frozen count above its ideal must carry a named holder. Returns nothing.

GBGCodingTools.TestHarness.allocation_completeness — Function
allocation_completeness(pkg, modules; exempt = Dict{Symbol,String}())

The derived completeness check of the allocation audit. The arguments are pkg, the package module; modules, its owned modules (the public surface is derived from them); and exempt, operation name to reason for the operations deliberately not audited.

Every exported in-place operation (a name ending in ! on the ownership-derived public surface) was exercised by @alloc_below, or is named in exempt with a reason; no exemption names a vanished operation; every recorded callee is a real package function. Runs as a @testset. Returns nothing.

source
GBGCodingTools.TestHarness.traffic_completeness — Function
traffic_completeness(pkg, modules; exempt = Dict{Symbol,String}())

The derived completeness check of the traffic audit, the twin of allocation_completeness over AUDITED_TRAFFIC_OPS. The arguments are pkg, the package module; modules, its owned modules; and exempt, operation name to reason for the operations deliberately not audited. Runs as a @testset. Returns nothing.

Parity, oracles, display, threads

GBGCodingTools.TestHarness.method_parity — Function
method_parity(pkg, modules, baseline; externals = (Base,))

The method-parity engine. The arguments are pkg, the umbrella module; modules, the package modules; baseline, the parsed test/method_parity_baseline.toml; and externals, the external modules whose generics the package extends.

Every [[generic]] entry {set, name, count, module} asserts the number of methods the named module defines for that generic, each set's total is asserted where the baseline states [set_total], the [module] table asserts the derived per-module counts, and detect_ambiguities over pkg must be empty. A moved number is reported with the instruction to refreeze deliberately, with the reason. Runs as a @testset. Returns nothing.

source
GBGCodingTools.TestHarness.oracle_registry — Function
oracle_registry(pkg, modules, registry, testdir)

The oracle-provenance engine. The arguments are pkg, the umbrella module; modules, the package modules; registry, the parsed test/oracle_registry.toml ([[operation]] name, class, evidence); and testdir, the directory the cited test files live in.

Every public value-returning operation (the derived surface minus the ! names) is classified; no classification names a vanished operation; every class is one of analytic | independent | property | relational | structural; no operation rests on relational alone; and every non-structural citation names a test file under testdir that exists and mentions the operation. Runs as a @testset. Returns nothing.

source
GBGCodingTools.TestHarness.display_gate — Function
display_gate(modules; no_display = Dict{Symbol,String}(), min_types = 1, falsify = true)

The display gate, DERIVED rather than listed: every concrete struct type of modules has a package-owned show or an exemption in no_display with a reason; an exemption whose type has a show after all is stale (a widened blind spot); an exemption naming a type no longer defined is stale; the enumeration must find at least min_types types, so a parser that stops matching fails rather than reporting a clean sweep. With falsify = true an empty parametric struct is planted in the first module and must be enumerated without a display. Runs as a @testset. Returns nothing.

GBGCodingTools.TestHarness.thread_digest — Function
thread_digest(probe_source; threads, project = Base.active_project()) -> String

Runs a probe in a fresh Julia process with a given thread count and returns its output — the cross-thread-count half of a bitwise-invariance check the in-process toggle cannot make. The arguments are probe_source, Julia source that prints digests with fnv_digest (which is prepended); threads, the -t value; and project, the --project it runs under. Returns the trimmed stdout.

Gates

GBGCodingTools.TestHarness.run_regressions — Function
run_regressions(dir; parent = Main) -> Vector{String}

The one include loop of the promoted witnesses. The arguments are dir, the consumer's test directory (@__DIR__ of runtests.jl; its regressions/ subdirectory is read, or dir itself when it is that directory), and parent, the module the wrapper modules are evaluated in.

Every *.jl directly under the regressions directory (sorted) is included into its own wrapper module Regression_<name>, so top-level helpers cannot collide across files. An empty directory is an honest state and runs nothing. Returns the list of files run.

source
GBGCodingTools.TestHarness.gate — Function
gate(; root = GBGCodingTools.Config.find_root())

The closure gate a consumer's runtests.jl ends with. The argument root is the consumer root, found by walking up from the working directory when not given.

It runs the quick doctor set and the closure gate of the two code instruments (bug-hunt, audit-changes) in-process, error()ing on a non-zero return so a test run cannot pass over an open hunt or audit round, and prints one banner line GBGCodingTools v<ver> gate (the TEST.PKG witness). Never the bare four-instrument gate: a test run must not fail on an open docs round. Returns nothing.
