GBGCodingTools.Config — Module
Config

The loader of a consumer's .gbg/config.toml. Config.read is the one way the config is obtained — by every verb, by the makedocs wrapper and by TestHarness.gate() — and Config.ConfigError is what a config that cannot be used raises. The helpers Config.glob_files and Config.resolve_anchor are the two readers of the config's path vocabulary (globs and file#heading anchors), shared with the doctor and the scans.

Two words this package overloads, both first met here. A SURFACE is the config's unit of "what gets read": a named set of files — rationale, pages, src, ext, literate, data, and the compounds docs and all — that every scan, engine, doctor check and instrument works over. An ANCHOR here is a file#heading reference into a document, and NOTHING else: elsewhere the same word is a hat or lane that runs at full strength rather than on the economy model (Preflight.resolve_hats), and a regular expression marking where a seed is planted (Seeds.select). Three unrelated senses, one word.

GBGCodingTools.Config.ConfigError — Type
ConfigError <: Exception

A config that cannot be used: absent, unparsable, invalid against the schema, or naming a path that does not resolve. The fields are:

  • msg — the message, with every violation listed.

GBGCodingTools.Config.find_root — Function
find_root(start = pwd()) -> Union{String,Nothing}

Walks up from start to the first directory holding .gbg/config.toml — the consumer root, the same walk the shim does. Returns that directory, or nothing when none is found.

source
GBGCodingTools.Config.glob_files — Function
glob_files(root, pattern) -> Vector{String}

Every regular file under root whose /-separated relative path matches the glob pattern (see glob_to_regex), as relative paths, sorted. A pattern without a wildcard names one file and matches it if it exists. Returns the list, empty when nothing matches.

source
GBGCodingTools.Config.glob_to_regex — Function
glob_to_regex(pattern) -> Regex

Turns a glob over /-separated relative paths into a regex: ** matches any run of directories (including none), * any run of characters within one segment, ? one character. Returns the anchored regex.

source
GBGCodingTools.Config.check_paths — Function
check_paths(cfg) -> Vector{String}

Every existence check the config implies (the doctor's CFG.SURFACES): each non-optional surface glob matches at least one file; each file#heading anchor resolves to exactly one heading; each module has a module <Name> block under src/; each [paths] entry is a directory; the glossary file exists and a non-empty built_html has a docs/ directory beside it; each extensions file, the docs/make.jl the config schema pins docs_build to name, each executable_claims file and, while seed_rounds is on, the seed catalogue exist. Returns the problems found, empty when all hold.
