GBGCodingTools.Reflection — Module
Reflection

The engines of /check-docs that reason about a package's docstrings against its code: argument coverage (Reflection.argcov), the displayed-versus-defined signature table (Reflection.signature_fidelity), unlinked cross-module first mentions (Reflection.xlink), a target linked twice in one docstring (Reflection.dupref), and the ownership-derived public surface (Reflection.package_operations) every completeness guard covers. Two constants of the docstring rubric — docs-rubric.md of the shared policy, its RULE.DOC.* rules — bind the argument checks: the count from which a docstring lists its arguments in the bulleted form (Reflection.ARGS_THRESHOLD), and the phrase that marks a thin allocating wrapper (Reflection.WRAPPER_PHRASE). The text scans need no loaded package; the two reflective ones load it.

GBGCodingTools.Reflection.argcov — Function
argcov(cfg; exempt = (hit -> false)) -> (hits, population, skipped)

The argument-coverage sweep over the src surface of the config cfg, driven FROM THE SIGNATURE: every positional and keyword parameter of a docstring's displayed signature must appear in its body as a code span, bare (n) or carrying its default (n = 2).

The arguments are:

  • cfg — the validated config, whose src surface names the files read.
  • exempt — the GBGCodingTools.Ledger's [exemption.match] predicate, called per trigger as exempt(hit); the trigger population is returned so the doctor can dry-run it.

The docstring rubric's exemptions are applied, and counted rather than silently dropped: an internal _-prefixed helper; a thin allocating wrapper (the body carries WRAPPER_PHRASE); a docstring with fewer than ARGS_THRESHOLD arguments and no keyword (the prose form, a human read).

Returns the hits, the number of parameters examined, and a named tuple of the skipped counts.

GBGCodingTools.Reflection.signature_fidelity — Function
signature_fidelity(cfg; pkg = load_package(cfg), examined = nothing) -> Vector{String}

Per exported binding, the displayed docstring signatures against the defined method table (positional names accent-normalised, keywords by name): a displayed keyword no method defines (a stale signature), a defined keyword no signature advertises, a displayed positional matching no argument name. The arguments are:

  • cfg — the validated config.
  • pkg — the loaded package, loaded from the config when not given.
  • examined — an optional counter the caller passes to learn how many bindings were actually compared, which is the scan's population: a package that exports nothing compares nothing, and a scan that measured nothing must say so rather than print clean.

Returns one message per discrepancy; an extension-homed binding with no methods loaded is reported as skipped.

source
GBGCodingTools.Reflection.xlink — Function
xlink(cfg; pkg = load_package(cfg), apply = false) -> Vector

Every bare mention of a public name owned by ANOTHER package module inside a docstring (the first mention, outside the signature and the arguments), as (file, line, name, owner). The arguments are:

  • cfg — the validated config.
  • pkg — the loaded package (loaded from the config when not given).
  • apply — rewrite each site to a qualified @ref link in place; default false, a dry run.

Returns the sites.

source
GBGCodingTools.Reflection.dupref — Function
dupref(cfg) -> Vector

The @ref targets linked more than once inside one docstring of the src surface (the docstring rubric caps a target at its first genuine mention; invisible in the rendered text). Returns named tuples (file, line, target, count, signature).

source
GBGCodingTools.Reflection.package_operations — Function
package_operations(pkg, modules) -> Set{Symbol}

The derived public surface: every exported function of the umbrella pkg and of its owned modules, plus every external generic a package module extends (found by walking the loaded modules and asking each function whether a package module owns one of its methods — a method defined under a qualified name creates no binding, so a namespace scan cannot see it). Internal helpers and closures never enter it. The arguments are pkg, the umbrella module, and modules, the owned modules. Returns the names.

source
GBGCodingTools.Reflection.WRAPPER_PHRASE — Constant
WRAPPER_PHRASE

The docstring rubric's spelling of a thin allocating wrapper — a docstring carrying it documents no arguments, @ref-linking its home instead — which is what makes the exemption detectable rather than a judgement.

source
GBGCodingTools.Reflection.ARGS_THRESHOLD — Constant
ARGS_THRESHOLD

The docstring rubric's constant (docs-rubric.md of the shared policy, its RULE.DOC.* rules): a docstring with this many arguments or more, or any keyword, documents them in the bulleted The arguments are: form; fewer are bound in prose. Not a config key.
