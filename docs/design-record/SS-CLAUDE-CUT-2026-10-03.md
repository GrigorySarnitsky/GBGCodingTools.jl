# What GBGStreamingStatistics' `CLAUDE.md` restates of the rulebook — measured 2026-10-03

A reader compared SS's `CLAUDE.md` (680 lines, at SS's head `4b990c8`) passage by passage with the
rulebook SS loads once wired (GBGCodingTools v2.0.0-rc.57's `.gbg/policy/*.md`: `docs-rubric.md`,
`latex-idiom.md`, `citations.md`, `testing-protocol.md`, `instruments.md`, `git-conventions.md`,
`asking.md`, `publication.md`, `glossary.md`), under SS's config as wiring writes it: no switches, no
settings, no declared harness contracts.

Each passage is marked `DUPLICATE` (delete it), `TRIM` (cut what goes, keep what stays), `CONFLICT` (SS's
text says something the rule contradicts: a question for the owner, not for the session) or `kept` (SS's
own). A passage restating one of the six harness contracts — `RULE.TEST.ALLOC_ZERO`, `PASS_AUDIT`,
`ORACLE_INDEPENDENT`, `METHOD_PARITY`, `SEED_PARITY`, `DEVICE_COST` — is kept while SS has not declared
that contract: each binds only a package that calls its `TestHarness` function from its suite, and until
SS does, SS's text is its only statement of it.

The list is a measurement, not a ruling: SS's session checks each item against the text before acting,
and against the rulebook at the version SS pins when it is wired, if that is later than rc.57. Three of
the conflicts below are already settled by the owner, each in the rule's favour, and need no new question:

- L671–674, `RULE.GIT.TRAILER`: the trailer is versionless (ruled 2026-09-08).
- L280–295, `RULE.TEX.LEFTRIGHT`: `\left`/`\right` is banned except in a formula the owner allows by
  name (ruled 2026-09-27). SS's blanket exemption for a system goes; each formula SS wants kept is a
