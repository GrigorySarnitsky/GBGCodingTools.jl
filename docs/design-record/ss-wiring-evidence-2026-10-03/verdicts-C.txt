## The statements (quoted once)

RULE.TEX.ONE_SPAN — A code span and a math span are never set against each other where the formula continues into or out of the name: where it says more than the name — a definition, or a symbol and then its definition — the name goes inside it as \texttt{…}, and where it only names what the code denotes, a connective joins the two. A formula finished at the edge the name sits on is not continued by it and is left as it is.
RULE.CIT.FULL_INLINE — A docstring cites author–year in its prose and carries the full reference in a `# References` section, identical to the canonical entry in title and DOI.
RULE.DOC.XLINK — A name another module owns, mentioned on its own, is linked at its first mention in a docstring, qualified so the link resolves; a name inside a code expression owes no link.
RULE.DOC.SIGNATURE_FIDELITY — The signature a docstring displays and the methods the module defines agree, argument for argument. (why: A displayed signature is what a reader calls; one the method table has moved past is a call that fails.)
RULE.DOC.REF_ABUT — A cross-reference never abuts a second code span; the whole call is the link text.
RULE.DOC.AI_BANNER — A rationale page and a rendered Literate example carry the provenance banner, verbatim; a script that is never rendered is not a page and carries none. (banner_pages unset = String[]; the banner is `!!! info "Written by AI, not regularly reviewed"` + its one line.)
RULE.TEX.SPACING — Spacing inside a formula is the renderer's: no thin space except before a differential, no medium or thick space, no negative thin space before a sized delimiter, and none of them doubled.
RULE.DOC.FIELDS — A type with named fields documents them in a `# Fields` section, in bullets: every bullet a real field, and every field at the head of a bullet, alone or with others; a field named only inside another's bullet has none. A sentence listing them, "The fields are …", is no such section.
RULE.TEX.RENDERED_MATH — Mathematics is written in a double-backtick span: never between dollar signs, and never inside a code span.
RULE.TEX.CODE_IN_MATH — A code identifier never sits inside a math span; inside a formula it is written \texttt{…}.
RULE.DOC.SIGNATURE_MIRROR — A docstring's signature block fits the house column of 88 characters, as rendered, and repeats only as much of the method as a reader needs.
RULE.DOC.SIBLING_LINK — The first mention of a sibling package links to that package's site; later mentions are bare.
RULE.DOC.INTERNAL_API — An API page puts its internal section last, holds no empty block of collected docstrings, and is never indexed.
RULE.CIT.DOI — Every reference carries a clickable DOI, or an Open Library link for a book, on its title. A work whose entry states it has no DOI — the words "no DOI", in any case — may carry on its title instead an https link to its stable public record.

## What the check missed, for the FALSE ones

- RULE.DOC.SIGNATURE_FIDELITY (4): the check compares positional parameter NAMES, so a docstring that names a positional slot `summary` while the method calls it `h` (or `batch` vs `samples`/`x`) is reported, although type, arity and position agree and the displayed call succeeds. Two sub-patterns: (a) a docstring on an empty generic function `function f end` whose methods live in another module (observe!, scale!); (b) a method directly below with a different positional name (observe_pairs!). If the rule means names too, the whole package's `summary` convention is in violation and the finding stands; the why ("a call that fails") says it does not.
- RULE.TEX.SPACING (2): the thin-space allowance "before a differential" is not recognised when the span wraps between `\mathrm` and `d…` (`\,\mathrm` at the line end, `du`/`dy` on the next line), or when the differential is written `\mathrm d` without braces.
- RULE.TEX.RENDERED_MATH (1): a Unicode comparison operator inside a code span (`degree ≥ 2`) is taken for mathematics; it is a Julia expression over a keyword argument. Borderline — the rule's text does not exclude it, but a code span of valid Julia is code.
